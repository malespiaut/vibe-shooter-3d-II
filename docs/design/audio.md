# Audio

All audio is synthesised or authored in-repo. No sampled audio from outside, no external music.

## Mixer

| Item | Contract |
|---|---|
| Output | 22050 Hz, stereo, signed 16-bit, SDL3 audio stream fed from `src/platform/` |
| Voices | 16 sound-effect voices + 4 music channels, integer mixing in 32-bit accumulators, clipped |
| Sources | `.snd` files (`tech.md`), 22050 Hz signed 8-bit mono |
| Spatialisation | Volume from distance via a 64-entry table (full within 2 u, silent past 24 u); stereo pan from the angle between view and source (8 steps). Computed by the game at start time and every 4 tics for moving sources. |
| Voice stealing | Same source restarting cuts its previous sound; otherwise the quietest/oldest voice is stolen. |
| Determinism | Audio never changes game state. Headless mode runs the mixer into a null sink (or `--audio-out <file.wav>` for evidence). |

## Sound effects

Generated by `tools/sfx.py` from parameter files `assets/src/sfx/<name>.json` (oscillators: square,
saw, triangle, noise; envelope ADSR; pitch sweep; lowpass; bit crush; layering). Deterministic per
seed. Output `assets/gen/sfx/<name>.snd`.

## Music

An in-engine 4-channel pattern sequencer with synthesised instruments (square with duty, triangle,
noise, and a short "pluck" made from filtered noise). Songs are text files
`assets/src/music/<name>.vmus`: header (tempo in tics per row, instrument definitions), then patterns
of 64 rows x 4 channels with note, instrument, volume and effect (arpeggio, slide, vibrato), then an
order list. Synthesis is integer, inside the mixer.

| Track | Use | Mood |
|---|---|---|
| `title` | title, menus | pentatonic "Egyptian" scale over a mechanical beat |
| `level_eg` | levels 1-2 | driving, sandstone, harp-like plucks |
| `level_docks` | level 3 | swung, river rhythm |
| `level_tomb` | level 4 | sparse, low drones, distant percussion |
| `level_dt` | levels 5-6 | industrial noise percussion, square bass |
| `level_climax` | level 7 | fast, both motifs layered |
| `boss` | level 8 arena | Woofu's anthem, a pompous march that falls apart in phase 2 |
| `intermission` | tally screens | short loop |
| `ending` | ending, credits | the title theme, slow and happy |
