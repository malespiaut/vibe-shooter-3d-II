# Level 5, Kibble Refinery (docs/design/levels.md section 5), layout half
# (issue #174): geometry, textures, light, doors, keys, switches, sludge,
# barrels, items and secrets. No enemies yet: the population issue places
# them on the named WAYPOINT entities below (@sludge_*, @vault_mastiff, ...).
# Built by tools/mkmap.py into maps/level5.vmap. Coordinates are (x, y) with
# y counted from the south (last layout row is y = 0), as in demo `goto`.
#
# Critical path (demos/level5-complete.demo):
#   Loading Bay      x 1-8,   y 1-8    start (2,4) facing east
#   Sludge Pits      x 11-25, y 1-13   grate walkways (=) over DAMAGE sludge (~ ;)
#   Control Tower    x 27-33, y 3-12   door D (26,9), blue key (32,4)
#   blue door B      (28,13), corridor x 28 y 14-16
#   Grinder Hall     x 22-33, y 17-22  switch S (21,20) on the west wall, used
#                                      from (22,20), opens the timed door T
#                                      (34,20) for 10 s (350 tics), 12 tiles
#                                      east across the sludge x 29-33;
#                                      gantry y 24-25 behind a BLOCK_ALL rail (_)
#   Antechamber      x 35-38, y 18-21
#   Lance Vault      x 36-38, y 22-34  Lance (37,23) fires tag 2: the riveted
#                                      wall L (37,35), 12 tiles away, slides open
#   Mastiff lair     x 35-39, y 36-38  violet key (37,38)
#   violet door V    (35,33), corridor y 33; ammo cache x 32-34 y 29-31
#   Packaging Line   x 10-30, y 31-38  conveyor rows; EXIT E (9,35) used from (10,35)
#
# Secrets (3), each a PUSHWALL with a SECRET cell (!) behind it:
#   F (34,6)  dt_screen_f1 among dt_screen_f0 walls in the Control Tower
#             -> room x 35-37 y 5-7, Sun Orb
#   H (20,14) dt_hazard wall behind the barrel cluster on the Sludge Pits
#             north island -> room x 19-21 y 15-16, Catnip Frenzy
#   C (20,30) dt_conveyor where the Packaging Line belt runs into the wall
#             -> room x 19-21 y 27-29, Scarab Plate
#
# Light: floodlit cells are dark 0-2 under dt_ceiling_light; the shadowed
# corners (, ; ') are dark 12-16, right next to them.
