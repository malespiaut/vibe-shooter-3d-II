# Level 1 "Sandbox Gate" (docs/design/levels.md section 1), 24x24, built by
# tools/mkmap.py into maps/level1.vmap. Coordinates are (x, y), y counted
# from the south (the last layout row is y = 0), as demo goto.
#
# Critical path: start plaza (6,1) -> gatehouse door D (6,8), straight ahead
# -> gatehouse (dark 8) -> inner gate door (6,11) -> Litter Courtyard (x 4-12, y 12-19,
# obelisk o and four pillars i) -> corridor (13-14,17) -> Shrine of the Green
# Ankh (x 15-21, y 15-19, key at (21,17)) -> back to the green door G (13,12),
# on the courtyard's east wall, seen from the inner gate before the key -> passage
# (14,10-12) -> Gate Winch Room (DT steel, x 14-22, y 2-9) -> EXIT lever E
# (23,5), used from (22,5).
#
# Shrine ambush: taking the key (PICKUP_TRIGGER, tag 4) opens the two
# eg_tomb_stone closet doors t (15,20) and (16,14), switch mode tag 4.
# Secrets: P (3,15) eg_paw_wall pushwall (the only paw wall on the map),
# slides west to (1,15) -> room x 1-2, y 16-18 (SECRET cell x (2,17)):
# Linen Wrap + 2 Fish Snacks. L (17,20) paler eg_sand_blocks2 pushwall in the
# shrine's eg_sand_blocks north wall, slides north to (17,22) -> lit alcove
# A (dark 0, SECRET cell X (19,21)): Charge Jar, seen from the shrine through
# the window W (19,20), a BLOCK_ALL floor cell.
#
# Outdoor cells have a ceiling until sky_dawn (#155) exists; #150 switches
# them to sky. Pillars and the obelisk are wall blocks until props (#131).
# DT scaffolds use dt_riveted_plate: dt_scaffold_sandstone (21 chars) does
# not fit the 16-char map texture name table.
