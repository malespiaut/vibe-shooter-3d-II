#   T (3,4)  door, mode timed, tag 2: opened by w, closes 105 tics later
#   3 (8,4)  door, mode switch, tag 3: opened by the trigger r
#   r (9,6)  walk-over TRIGGER, tag 3 (also fires the LIGHTS entity)
#   ~ (11,7) DAMAGE floor, 5 health per 16 tics
#   E (1,8)  EXIT wall, used from (1,7)
#   P (3,8)  PUSHWALL, slides north 2 tiles to (3,10); ! (3,9) is SECRET
#   Q (7,8)  PUSHWALL, (7,10) is wall: slides 1 tile to (7,9)
