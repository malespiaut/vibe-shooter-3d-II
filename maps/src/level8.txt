# Level 8 "Throne of Woofu" (docs/design/levels.md section 8): 48x48, built
# by tools/mkmap.py into maps/level8.vmap. Layout pass only (#194): no
# enemies and no boss; WAYPOINT entities named @... mark the spots for the
# population issue. Coordinates are (x, y), y counted from the south (the
# last layout row is y = 0), the same as demo `goto`.
#
# Tags: 1 = T_BOSS (the follow-up gives Woofu tag 1; his death fires it:
#           the exit door X opens and the 16 RESPAWN_ITEMs stop restocking)
#       2 = T_ARENA (TRIGGER cell T: the START_OPEN door O closes behind)
#
# Critical path (demos/level8-walk.demo):
#   Apex landing (2-7, 2-8), start (4,5) facing east -> door D (8,5)
#   -> Processional Way (9-44, 2-8), 36 tiles long: gold statue columns g
#      every 4 tiles on y = 3 and y = 7, Woofu banner wall w along the north
#      side, gold glyph band b along the south; one spot per enemy type in
#      introduction order (@proc_mutt .. @proc_shield) -> door D (41,9)
#   -> Hall of Tributes (38-45, 10-17), gold walls, violet key (41,16)
#   -> violet door V (37,14) -> corridor y = 14 west, x = 24 north
#   -> START_OPEN door O (24,18) (mode=switch tag 2) -> passage (24,19)
#   -> TRIGGER T (24,20), tag 2: O closes for good (switch mode: `use`
#      cannot reopen it; the trigger fires once). T is two tiles past O so
#      the player never overlaps O when the tag fires (an overlapped closing
#      door re-opens and would then stay open).
#   -> Throne Arena (12-35, 20-43): 24x24 open sky at sunset, dark 2,
#      4 sandstone pillar clusters S (2x2 core + 2 single pillars):
#      SW core (17-18,25-26), SE (29-30,25-26), NW (17-18,37-38),
#      NE (29-30,37-38).
#   -> exit: door X (24,44), mode=switch tag 1 (only Woofu's death opens it)
#      -> closet (24,45) -> EXIT E (24,46), used from (24,45) facing north.
#
# Restock alcoves l (dark 6, roofed), 2x2 behind a 1-tile mouth in the side
# walls, each with 4 RESPAWN_ITEMs tag 1: Sun Shard (60), Charge Vial (54),
# Yarn Bundle (56), Scarab (58):
#   NW (9-10, 39-40)  NE (37-38, 39-40)  SW (9-10, 23-24)  SE (37-38, 23-24)
# Kennel pods: BOSS_POD in 3-wide niches n of the north wall (17,44),
# (30,44) facing south and of the south wall (17,19), (30,19) facing north
# (the pod's Chompers spawn to its sides, inside the niche).
#
# Secrets (2):
#   P (30,9) eg_paw_wall pushwall, the one raised-paw statue among the Woofu
#     banners of the Processional Way's north wall, pushed north -> (30,10)
#     SECRET: Golden Sardine (31,11)
#   M (43,18) eg_mural pushwall, the fish tribute pile in the Hall of
#     Tributes' north wall, pushed north -> (43,19) SECRET: Catnip Frenzy
#     (44,20)
#
# Statues: there is no dog-headed Woofu statue texture or sprite on main;
# Woofu is shown by dt_banner (paw banner on chrome) wall panels and gold
# statue columns (eg_gold_pillar), plus hanging DOG_BANNER props.
