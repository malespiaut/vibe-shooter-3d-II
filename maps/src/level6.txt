# Level 6 "Sphinx Under Construction" (docs/design/levels.md section 6),
# 48x48, built by tools/mkmap.py into maps/level6.vmap. Coordinates are
# (x, y), y counted from the south (the last layout row is y = 0), as demo
# goto. LAYOUT ONLY: no enemies yet (issue #178 adds the 52 and the named
# WAYPOINTs below mark their spots).
#
# Critical path:
#   workers' camp (x 2-30, y 2-9, start (4,3) facing north)
#   -> dt_door D (4,10) -> scaffold climb (x 2-10, y 11-46): a zigzag of
#      dt_riveted_plate scaffold walls, one gap per level, climbing north
#   -> one-way drop O (11,44), opens only from the west (side=west): onto
#      the upper walk (x 12-21, y 44-46) on the Sphinx's back
#   -> one-way drop N (19,43), opens only from the north (side=north):
#      down the chute (19,40-42) into Paw Plaza
#   -> Paw Plaza (x 12-30, y 20-39): two sandstone paws (x 22-29, y 25-26
#      and y 33-34, eg_ashlar claws at x 22), detached from the chest wall
#      by the x = 30 column so both paws can be walked around (flanking
#      routes). Litter Satchel (23,28) and green key (28,30) lie between
#      the paws, in front of the green door.
#   -> green door G (31,30) into the Sphinx's chest
#   -> Heart Chamber (x 32-46, y 27-33): 15 tiles long, the Sphinx Howler
#      on its pedestal at the east end (45,30) between gold pillars
#   -> eg_door d (34,34) -> Grinding Room (x 32-46, y 35-46): the face
#      carving (x 36-42, y 38-42, gold-striped headdress, its muzzle ground
#      down to dt_steel_cracked), floor below (y 35-43), scaffold above
#      (y 45-46) behind a railing with gaps at x 34 and x 44; blue key on
#      the scaffold behind the face (39,46)
#   -> back through the Heart Chamber to the blue door B (39,26)
#   -> lift landing (x 36-42, y 20-25) -> EXIT lift switch E (39,19),
#      used from (39,20) facing south.
#
# No soft-lock: O and N are the only one-way doors. Everything after them
# (Satchel, both keys, Howler, both doors, exit) is in the region they lead
# into, and that region is connected without one-way doors. The camp and
# the scaffold (and secret 1) come before the drops.
#
# Secrets:
#   1. P (11,17): a sandstone block with a fresh-cut edge (eg_sand_cracked,
#      the only use of that texture on the map) in the scaffold's east wall.
#      Pushed from (10,17) it slides east to (14,17) -> room x 12-14,
#      y 16-18, SECRET cell x (12,16): Golden Sardine.
#   2. Q (13,40): scaffold boards (eg_planks as a wall, used only here) in
#      the plaza's north wall, next to the gap W (15,40), a BLOCK_ALL cell
#      through which the plaza sees up into the lit nook. Pushed from
#      (13,39) it slides north to (13,42) -> nook x 12-15, y 41-42, SECRET
#      cell X (12,41): Cat's Eye Amulet + Sun Orb.
#
# Outdoor cells have a dt_concrete ceiling: sky_midday (#155, PR #169) is
# not on main yet. The follow-up switches the `.` legend to `ceil=sky`.
# dt_scaffold_sandstone (21 chars) does not fit the 16-char texture name
# table, so the scaffold uses dt_riveted_plate (as level 1 does).
