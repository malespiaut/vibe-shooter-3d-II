# Level 2, The Mew-seum (docs/design/levels.md section 2). 32x32 EG interior,
# built by tools/mkmap.py into maps/level2.vmap. Layout generated once by
# hand-placed rectangles, then edited here; this file is the source.
# Coordinates in comments are (x, ty) with ty counted from the south (the
# last layout row is ty = 0), as `entity` lines and demo `goto` use.
#
# Critical path: lobby (SW) -> D (5,8) -> Hall of Mummified Mice -> O (5,21)
# -> Scattergun gallery -> O (11,25) -> vestibule -> D (14,25) -> Gift
# Shop (green key behind the counter) -> green door E (18,21) -> Hall of Pharaohs -> office door D
# (26,15) -> Curator's Office (blue key) -> blue door B (27,21) -> loading
# dock -> exit lever X (28,31).
#
# Tags:
#   2  TRIGGER row t (3-7,15) in the middle of the Mice hall opens the two
#      sarcophagus closets Z (2,15) and (8,15): 2 Chompers.
#   3  taking the Scattergun (PICKUP_TRIGGER) closes the two START_OPEN
#      gallery doors O and opens the 3 closets Q: 6 Chompers carrying tag 10.
#      KILL_TRIGGER tag 10 param 3 fires tag 3 again when all of them are
#      dead: the O doors (mode switch, so the player cannot open them
#      earlier) reopen and stay open.
#   4  TRIGGER column u (24,16-20) in the Hall of Pharaohs opens the side
#      closets R (12,15) and (18,15): Chompers behind the player.
# Secrets (3): wrong-way statue w (14,16, eg_glyph_band among the
# eg_gold_pillar statues) -> Scarab Plate; Staff Only door f (21,28, an
# eg_door that is a pushwall in the eg_museum_plaque gift shop) -> Catnip
# Frenzy; cracked display wall k (21,11, eg_sand_cracked) -> 2 Tuna Tins.
# The vestibule's closed door keeps the gift shop out of sight and earshot
# of the gallery fight.
# Ambush closets use eg_sand_blocks2 (x) so they read as different walls.
# Light: lobby/gift shop 6, gallery/office 8, halls 10, closets/dock 12.
