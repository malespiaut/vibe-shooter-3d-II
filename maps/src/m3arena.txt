# maps/m3arena.vmap. Test map for demos/m3-arena.demo, not a game level: six
# rooms in a row, west to east, one per regular enemy type, each holding the
# weapon that counters the next room's enemy (enemies.md Counter column).
# Coordinates are (x, ty) with ty counted from the south (the last layout row
# is ty = 0), as `entity` lines and demo `goto` use.
#
#   R1 x 1-7   Mutt room: 3 Mutt Troopers, backs turned. Start, Claws + Pistol.
#   R2 x 9-15  Chomper room: 1 Chomper faces the door; taking the Scattergun
#              (PICKUP_TRIGGER tag 2) opens the closet Q (12,8): 3 more.
#              Sistrum Repeater + Charge Jar by the east door.
#   R3 x 17-23 Pomeranian room: 2 Plasmagunners. Scarab Launcher + Crate.
#              Secret: pushwall P (20,8) slides north onto ! (20,9): Tuna Tin.
#   R4 x 25-31 Dachshund room: 1 Howitzer, the green key, Sphinx Howler + Sun Orb.
#   R5 x 33-39 Shieldbearer room behind the keyed (green) door G (32,4).
#              Eye of Ra Lance + Sun Orb. Wall switch s (36,0), tag 1, opens
#              the switch door S (40,4).
#   R6 x 41-55 Mastiff hall: 1 Juggernaut 7 u past the switch door. Exit
#              switch X (56,4), used from (55,4).
# Doors D are mode stay: a closed door stops noise (ai_noise floods open
# cells only), so each room wakes only when its door opens.
# Skill 2 (and 1, 3): 12 enemies.
