# Level 4 "Tomb of Tutankhamew" (docs/design/levels.md section 4), 40x40,
# built by tools/mkmap.py into maps/level4.vmap. Coordinates are (x, y), y
# counted from the south (the last layout row is y = 0), as demo goto.
#
# Critical path: start (19,2) -> Brazier Walk (x 18-20, y 5-14) -> hub door
# (19,15) -> Hall of Four Doors (hub, x 14-25, y 16-25) -> north passage N
# (19,26), START_OPEN -> Antechamber of Yarn (x 15-23, y 28-33: violet key,
# Scarab Launcher) -> violet door V (24,31) -> First Shell hall (x 25-35,
# y 28-34, Dachshund on the ledge x 37-38; the ledge edge x 36 is a tiled
# BLOCK_MONSTER strip that keeps it up there; BLOCK_ALL would also block
# sight and shots, game_tile_blocks) ->
# door (32,27) -> Shifting Hall switch room (x 29-35, y 22-26), switch T
# (36,24) fires tag 1 -> east wing (x 27-35, y 16-20) through e (32,21) ->
# hub east wall w (26,18) -> hub -> hub west wall w (13,20) -> west wing
# (x 4-12, y 17-23) -> Burial Chamber door (8,24) -> green key (8,31) ->
# back to the green door G (7,16) -> exit stair (x 5-9, y 4-15) -> EXIT
# lever E (7,3), used from (7,4).
#
# Shifting Hall (tag 1, the map's only tag): N closes (START_OPEN, mode
# switch, so it never reopens), the three wall-textured switch-only doors
# e (32,21), w (26,18) and w (13,20) open. The east and west wings hold
# 4 Mutts and 2 Poms sealed in until then.
# No soft-lock: before the switch every area (start, walk, hub, antechamber,
# hall, switch room) is connected and the switch is reachable once the
# violet key (in the antechamber, behind no door) is taken. The switch can
# only be used from inside the switch room, and the tag opens e right next
# to it: from the switch room, east wing -> hub -> west wing -> Burial
# Chamber (green key) -> green door -> exit stair -> EXIT are all open. The
# north side (antechamber, hall) stays connected to the switch room, the
# start and the walk stay connected to the hub through (19,15). The doors
# that open never close (mode switch), and nothing else uses tag 1.
#
# Light: dark 14-20, the Burial Chamber (d) is the darkest at 20 and holds
# only Dachshunds (visible reticle) and Chompers (melee), no hitscan enemy.
# Brazier cells b are dark 0 islands; the brazier props of #131 go on them
# once it is merged. Mutts in the Brazier Walk stand at dark 16-18 between
# the islands, backs turned (their LEDs are the telegraph).
#
# Secrets: M (15,2) eg_mural pushwall (the only mural on the map: the
# hieroglyph wall), slides west to (13,2) -> closet x 12-14, y 1-3 (SECRET
# (12,2)): Ninth Life. K (25,35) pushwall in the First Shell hall's dark
# north-west corner, marked by the single lighter tile l (25,34), slides
# north to (25,37) -> closet x 24-26, y 36-38 (SECRET (24,37)): 2 Tuna Tins
# + Scarab Crate. F (4,32) the middle of a three-block sarcophagus on the
# Burial Chamber's west wall (eg_gold_pillar like every sarcophagus), slides
# west to (2,32) -> alcove x 1-3, y 31-33 (SECRET (1,32)): Cat's Eye Amulet.
