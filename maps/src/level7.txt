# Level 7 "Pyramid Server Farm" (docs/design/levels.md section 7): 56x48,
# built by tools/mkmap.py into maps/level7.vmap. Layout pass only (#179):
# no enemies; WAYPOINT entities named @... mark the spots for the
# population issue. Coordinates are (x, y), y counted from the south (the
# last layout row is y = 0), the same as demo `goto`.
#
# Critical path (demos/level7-complete.demo):
#   Entry atrium (1-10, 1-9), start (6,5) facing east -> door D (11,4)
#   -> Cooling Hall (12-43, 2-6), 32 tiles long, pumps on both walls,
#      green key (42,4) at the far end -> green door 1 (40,7)
#   -> Server Maze, lit main aisle x = 40 (y 8-25) with two START_OPEN
#      doors O (40,12) and (40,20), side bays (42-45, 9-11) and (42-45, 16-18)
#   -> switch room (37-44, 26-30), Blackout switch B (40,31) on its north wall
#   -> tag 1: the O doors close for good (mode=switch: `use` cannot reopen
#      them), the maintenance walls M (36,28) and (34,22) and the hatch H
#      (36,16) open, and the LIGHTS entity switches every cell to dark_alt
#   -> the dark west maze (17-35, 9-30), a serpentine through five rack
#      bands, out at (16,10) -> corridor x = 14 -> door D (12,19)
#   -> Uplink Core (3-11, 18-26): ring around a 3x3 screen pillar (6-8,
#      21-23), blue key (7,25), 4 closets behind switch-only doors (C tag 20:
#      north (9,27), south (7,17); K tag 21: west (2,22), east (12,23)) for
#      the population's two kill-trigger waves -> blue door 2 (5,27)
#   -> corridor x = 5 -> Broadcast Bridge: entry platform (3-7, 37-43), a
#      1-wide bridge y = 40 over a BLOCK_ALL void (8-43, 36-44), violet key
#      (36,40), Dachshund platforms f (20-22,44) and (30-32,36)
#   -> one-way door > (44,40), opens from the west only (the drop)
#   -> landing (45-53, 37-43) -> violet door 3 (49,36) -> exit room
#      (47-53, 31-35) -> EXIT E (50,30), used from (50,31) facing south.
#
# No soft-lock after the Blackout: the switch room's only ways out after tag
# 1 are M (36,28) into the dark maze, and the dark maze has a single
# continuous route to the Uplink Core; the blue and violet keys are both
# past that point, and nothing behind the closed O doors is needed.
#
# Secrets (4):
#   r (43,15) dt_rack_odd pushwall (the only odd rack) in the south wall of
#     the north bay, pushed south -> (43,14) SECRET: Scarab Plate
#   G (4,10) eg_gold_pillar pushwall in the atrium's glyph-band north wall,
#     pushed north -> (4,11) SECRET: Golden Sardine
#   H (36,16) maintenance hatch (switch door, tag 1), only open after the
#     Blackout, off dark band 4 -> (37,16) SECRET: Ninth Life
#   t (44-50,4) dead-end cable trench east of the Cooling Hall; c (51,4)
#     dt_steel_cracked pushwall -> (52,4) SECRET: Sun Orb + Scarab Crate
#
# Dark layers: lit areas are dark 2-6; the maze (aisle, switch room, racks,
# dark bands) rises to dark_alt 20-26. Fullbright LEDs of dt_server_rack and
# the screens ignore cell darkness and stay readable. Areas past the maze
# rise by 4.
