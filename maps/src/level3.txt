# Level 3 "Nile Catwalks" (docs/design/levels.md section 3), 40x32, built by
# tools/mkmap.py into maps/level3.vmap. Coordinates are (x, y), y counted
# from the south (the last layout row is y = 0), as demo goto.
#
# Critical path: pier 1 (x 3-7, y 1-11, start (4,1) facing north) -> door
# (4,12) -> Customs House (x 1-13, y 12-23): entry hall, door (7,17) -> west
# office (blue key (3,21)), door (8,20) -> east office -> back to the hall,
# Sistrum Repeater (12,15) by the blue door B (13,15) -> Barge Crossing
# catwalk (x 14-28, y 14-17, crates c, 3 Poms at the far end) -> pump yard
# (x 29-38, y 12-20) -> switch S (30,11) opens the Pump House timed door T
# (36,11) for 8 s (param 8 = 280 tics); the switch can be pressed again,
# and U (38,9) is the same switch from inside -> Pump House (x 29-37,
# y 2-10, 2 Chompers) -> door H (28,8), catwalk (26-27,8), door (25,8) ->
# Lighthouse of Paw-ros (x 15-25, y 1-11): the outer ring (shut at
# (24,7), doors d at (20,10), (16,6), (20,2)) runs all the way round the
# central pillar to door (23,5), then the inner ring (blocked at (22,6))
# runs round to the green key at the top, (22,7). Taking it (PICKUP_TRIGGER
# tag 3) opens the shortcut door K (24,7) back to the entrance -> back
# through the pump house (switch U) -> green door G (33,21) -> exit yard (x 31-36, y 22-29)
# -> barge gate EXIT E (34,30), used from (34,29).
#
# Barge Gate: the TRIGGER cell t (33,22) right behind the green door fires
# tag 2, which opens the four closet doors k (30,24), (30,27), (37,24),
# (37,27): 6 Mutts and 2 Poms. A trigger right behind the door stands in
# for "when the green door opens": doors fire no tag of their own.
#
# Water: ~ cells are BLOCK_ALL with an eg_nile floor and the dusk sky.
#
# Secrets:
# 1. The crate stack north of the catwalk has a gap at (21,17): a dead-end
#    pier (21,18-24) ends at the boathouse plank wall Q (21,25), a pushwall
#    that slides north to (21,27) -> SECRET Y (23,26): Litter Satchel.
# 2. From the west office, the window W (5,23) (BLOCK_ALL, eg_nile floor)
#    looks over the water at a lit annex (x 3-9, y 25-26, dark 0). The
#    cracked block P (10,23) in the east office's north wall slides north
#    to (10,25) -> (9,24) -> annex, SECRET X (4,26): Scarab Launcher + 4
#    Scarabs.
# 3. The fish mural F (28,4) on the pump house's west wall (eg_mural, used
#    nowhere else) slides west to (26,4) -> nook, SECRET Z (27,3): Golden
#    Sardine.
#
# Crates are wall blocks until decoration props (#131/#206) exist.
